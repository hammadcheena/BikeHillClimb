BIKE HILL CLIMB - Lightweight Android Game

Open this folder in Android Studio.

Game:
- 2D side-view bike
- Gas on right side
- Brake on left side
- Simple hill terrain
- Score and distance
- Tap after game over to restart

ADS:
This starter project intentionally contains no live ad IDs.
For publishing/earning, add Google AdMob after the game works.
Use Google's test ad IDs during development, then replace them with
your own AdMob IDs before release.

Build:
Android Studio -> Open -> select this folder -> Run.
For Play Store use a signed Android App Bundle (AAB).
